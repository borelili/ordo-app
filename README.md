# 待办清单 App

一款功能完整的 iOS 待办事项管理应用，类似滴答清单，使用 SwiftUI 和 SwiftData 开发。

## ✨ 核心功能

### 📝 任务管理
- ✅ 创建、编辑、删除待办事项
- ✅ 标记任务完成/未完成
- ✅ 添加任务描述和备注

### 🏷️ 分类和组织
- 📂 自定义任务列表
- 📊 智能列表：全部、今天、已计划、重要、已完成

### ⚡ 优先级管理
- 🔵 低优先级
- 🟢 中优先级
- 🟠 高优先级
- 🔴 紧急

### 📅 时间管理
- 📆 设置截止日期和时间
- ⏰ 提醒通知功能

### 🔍 搜索和筛选
- 🔎 快速搜索任务
- 🎯 按列表筛选
- 📋 按状态筛选

## 🚀 快速开始

### 运行项目

1. **在 Xcode 中打开项目**
   - 双击 `TodoAPP.xcodeproj` 文件

2. **选择模拟器**
   - 点击顶部的设备选择器
   - 选择 iPhone 15 Pro

3. **运行**
   - 点击运行按钮 ▶️ 或按 `⌘ + R`

## 📂 项目结构

```
TodoAPP/
├── TodoAPPApp.swift          # 应用入口
├── ContentView.swift         # 主界面（包含所有视图组件）
├── Models/                   # 数据模型
│   ├── Task.swift           # 任务和子任务模型
│   ├── TaskList.swift       # 列表模型
│   └── Tag.swift            # 标签模型
└── Managers/                 # 管理器
    └── NotificationManager.swift  # 通知管理
```

## 💡 使用说明

### 创建任务
1. 点击右上角 ➕ 按钮
2. 输入任务标题
3. 可选：设置优先级、截止日期等
4. 点击"完成"

### 管理列表
1. 在侧边栏点击"新建列表"
2. 自定义列表名称

### 搜索任务
使用顶部搜索栏快速查找任务

## 🔧 技术栈

- **SwiftUI** - UI 框架
- **SwiftData** - 数据持久化
- **UserNotifications** - 本地通知

## 📱 系统要求

- iOS 17.0 或更高版本
- Xcode 15.0 或更高版本
